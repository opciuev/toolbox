# PySide6 章节演示实验室

本目录为《PySide6 基础教程》配套的可运行演示，代码以书中对应章节为依据。每章采用同一结构：

- 第二章起使用 `lesson.ipynb`：按网页/PDF 顺序完整保留每个小节和原书代码块，并提供可运行补充与小练习。
- `demo.py`：第二章起使用的独立 Qt 窗口程序。
- 第一章不使用 Notebook，只保留原书文件名 `app.py`、Windows 批处理和 macOS 等价启动脚本。
- 第二章 2.3–2.3.4 的 6 个事件示例，另外保存在 `02-Qt基础对象/2.3-事件`，每个文件都能独立运行。
- 个别章节会增加书中需要独立启动的辅助脚本，例如第三章的 `command_line_demo.py`。

## 使用方法

### 方式一：运行真实窗口演示

在终端进入对应章节目录，运行：

```bash
python3 demo.py
```

### 方式二：使用 Notebook

1. 在 VS Code 中打开对应章节的 `lesson.ipynb`。
2. 安装或启用 VS Code 的 Python 与 Jupyter 扩展。
3. 选择已经安装 PySide6 的 Python 解释器。
4. 原书代码保存在 Markdown 单元格中；需要验证时运行标有“可运行补充”的代码单元格。

当前系统 Python 已安装 PySide6，但尚未安装本地 Jupyter 运行组件；本目录不会擅自安装额外软件。

### 完整性检查

在 `章节演示` 目录运行：

```bash
python3 check_notebook_coverage.py
```

脚本会逐项对照 `ch02.html`、`ch03.html` 与对应 notebook 的全部标题和代码块。只有检查显示 `PASS` 的章节才在下方标记完成。
